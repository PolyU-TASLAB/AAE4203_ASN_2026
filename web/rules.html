Submission guide

Submit both CSV files to your assigned group folder. Official groups are G01–G20. Only the benchmark file is scored for the leaderboard; your own-data file is still required.

Open Google Drive · TA folder ↗

The filename must match the group folder. Do not upload into the TA folder root or another group's folder. Names such as G05_benchmark (1).csv and G05_benchmark_old.csv are ignored.

2 · Exact CSV format

Save a comma-separated text file with this exact header and exactly five columns, in this order. Use one row per solved epoch, sorted by GPS week and time of week. Do not repeat timestamps.

gps_week,gps_tow_s,x_ecef_m,y_ecef_m,z_ecef_m
2442,460800.0,-2418202.586,5385847.524,2405648.799
2442,460801.0,-2418202.174,5385847.238,2405648.952

These are illustrative values from the course materials, not an answer file. Use the GPS week, times and computed coordinates of your actual dataset. Do not copy GPS week 2442 into your results. Check the current benchmark epoch information on the leaderboard.

ColumnRequired format
gps_weekInteger GPS week, e.g. 2442; no decimal point
gps_tow_sSeconds of GPS week, at least one decimal; 0 ≤ value < 604800
x_ecef_mWGS-84 ECEF X in metres, exactly 3 decimal places
y_ecef_mWGS-84 ECEF Y in metres, exactly 3 decimal places
z_ecef_mWGS-84 ECEF Z in metres, exactly 3 decimal places
  • No latitude/longitude/height, centimetres, millisecond time tags, NaN, infinity, extra index columns or trailing commas.
  • Use a normal minus sign - for negative numbers and decimal notation, not scientific notation.
  • Omit epochs without a solution rather than writing zero or NaN positions. Missing epochs reduce availability.
  • Both benchmark and own-data files follow the same five-column format. Their timestamps may differ.

Check before uploading

From the project root, run:

python tools/check_submission.py G05_benchmark.csv G05_owndata.csv

If the TA gives you the standalone checker, run python check_submission.py G05_benchmark.csv G05_owndata.csv in its folder. Fix all format errors. Dataset-specific time warnings for own data should be checked against your recording; passing a format check does not guarantee a rank or an accurate solution.

3 · Upload and improve

  1. Verify each algorithm version on the example dataset first.
  2. Export and check both CSV files, then upload them to your group folder using the Drive link above.
  3. Keep the leaderboard open. The server scans every 10 seconds by default after Drive Desktop syncs the upload; synchronization adds its own delay.
  4. Replace the existing benchmark file whenever you improve the solution. Do not create a second copy with the same name.
  5. Record the method and result for each version in your report's ablation table.

Latest file, not best-ever score. A worse or invalid replacement supersedes your earlier result. Keep the intended final files in the folder through the deadline announced on Blackboard. A rank does not mean both required files have been submitted.

The tutorial schedules a preliminary leaderboard at about 2:50 from the session start. The teaching team publishes the final leaderboard on Blackboard using the deadline submissions.

4 · How ranking works

Epochs are matched by GPS week and time of week on a 0.1-second grid. Errors are rotated into East–North–Up at the reference position of each matched epoch.

Availability A = 100 × matched epochs / reference epochs
2D RMSE = sqrt(mean(East_error² + North_error²))
3D RMSE = sqrt(mean(East_error² + North_error² + Up_error²))
2D P95  = 95th percentile of sqrt(East_error² + North_error²)
  • Only valid benchmark submissions with A ≥ 90% receive a rank.
  • Lowest 2D RMSE first; ties are broken by 3D RMSE.
  • The leaderboard shows Rank, Group, Version, 2D RMSE, 3D RMSE, 2D P95 and Availability.
  • For example, 8.9 m error with 71% availability is not ranked, even if its error is lower than another group's.
  • Your own-data CSV is required for submission completeness but is not part of the benchmark ranking gate.

5 · Before the deadline

  • Both required CSV files are present in your own group folder and pass the format checks.
  • Your GitHub repository reproduces both CSV files. The teaching team may re-run your code.
  • Your report includes the methods tried, results, final metrics and the required AI-use statement.
  • Check Blackboard for the deadline, final leaderboard and how rank contributes to your mark.
